# Sales Dashboard

## 📊 Project Overview

This project is a Sales Dashboard created using Microsoft Excel to analyze and visualize sales data.

The dashboard provides useful insights into sales performance and helps in understanding business trends.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Data Analysis

## 📈 Key Features

- Sales performance analysis
- Interactive charts and visualizations
- Sales trends analysis
- Easy-to-understand dashboard
- Data filtering and summarization

## 📂 Project Files

- Sales_Dashboard.pdf – Dashboard preview
- Sales_Dashboard_1000_Rows.xlsx – Source sales data

## 🎯 Objective

The main objective of this project is to analyze sales data and present meaningful insights through an easy-to-understand dashboard.
